Tinjauan Masalah & Solusi

Tantangan Pengelolaan Surat & Solusi Terintegrasi

Transformasi dari pembukuan spreadsheet manual yang rentan kesalahan menjadi aplikasi web cloud yang terkontrol

Kendala Sistem Sebelumnya

  • Penempatan Baris Keliru: Data surat masuk baru kerap mendarat di baris paling atas (Row 2), menimpa header dan mengacak template.
  • Bahaya Hapus Baris (deleteRow): Aksi hapus baris fisik merusak urutan template dan membuat seluruh nomor urut di bawahnya bergeser ke atas.
  • Nomor Agenda Tertahan: Sistem sempat merekomendasikan nomor lama 609, bukan melanjutkan di bawah 620 menuju 621.
  • Ketergantungan Jaringan Penuh: Jika koneksi sekolah terputus, pekerjaan tata usaha terhenti total.

Solusi & Standardisasi Baru

  • Smart Slot Finder: No. Urut Surat Masuk 218 langsung mendarat presisi di Baris 217; Surat Keluar 621 langsung mendarat di Baris 643.
  • Safe Clear-Only Delete: Hapus data hanya mengosongkan sel teks tanpa menghapus baris fisik; Nomor Urut tetap utuh 100%.
  • Non-Destructive Update: Edit data hanya memperbarui nilai perihal/tanggal tanpa merusak atau menimpa kolom nomor urut.
  • Offline-First Resilience: Pencatatan tetap berjalan saat internet padam; otomatis sinkron saat online.
Arsitektur Solusi

Arsitektur Sistem 3 Lapis (Decoupled Serverless PWA)

Struktur komputasi nirserver yang menghubungkan antarmuka modern langsung dengan Google Workspace

1. Client & PWA Layer

Web Browser / Smartphone / Tablet

  • Antarmuka responsif (HTML5, CSS3, JavaScript Vanilla).
  • Service Worker (sw.js) untuk akses offline instan.
  • LocalStorage cache untuk respons instan (0 ms).
  • Generator Nomor Otomatis & live copy clipboard.

2. Logic & API Layer

Google Apps Script Engine v3.0

  • REST API Endpoint (doPost & doGet Handler).
  • Smart Row Slot Finder (Presisi Kolom A & D).
  • Non-Destructive Update & Clear-Only Delete.
  • Base64 Stream Decoder & Drive Uploader.

3. Cloud Storage Layer

Google Workspace Ecosystem

  • Sheet: SURAT KELUAR 2026 (Kolom A - N).
  • Sheet: SURAT MASUK 2026 (Kolom A - J).
  • Folder Google Drive: Arsip Surat SMA YWKA.
  • Checkbox otomatis Kolom B (Terverifikasi Drive).

Modul Surat Keluar

Mekanisme Surat Keluar: Lanjut Nomor 620 ke 621

Menjamin nomor agenda berlanjut tepat di bawah nomor terakhir terisi sesuai format kedinasan

Formula Penomoran Otomatis

  • Baseline Data Terakhir: Baris 642 terisi No. Agenda 620 ("Surat Pernyataan Peserta FinExpo 2026").
  • Auto-Recommendation: Sistem secara otomatis menetapkan nomor berikutnya adalah 621.
  • Format Kedinasan: [Kode] / [No. Agenda] / SMA YWKA TU / [Bulan] / [Tahun]
    Contoh: 421.3 / 621 / SMA YWKA TU / X / 2026.
  • Dukungan Sub-Nomor: Mendukung sub-nomor misal: 621.a untuk surat susulan.

Penempatan Presisi di Spreadsheet

  • Scan Kolom D: Apps Script mencari baris dengan No. Agenda 621.
  • Mendarat di Baris 643: Data langsung mengisi Baris 643, tepat di bawah Baris 642 (Agenda 620).
  • Proteksi Template: Kolom A (No. Urut 664) dan Kolom E (/SMA YWKA TU/ ) tetap terlindungi dan tidak tertimpa.
  • Ceklis Otomatis Kolom B: Jika ada berkas PDF terunggah ke Drive, Kolom B otomatis dicentang (TRUE).
Modul Surat Masuk

Mekanisme Surat Masuk: No. Urut 218 & Google Drive

Pemberesan kendala penempatan data di bagian atas sheet; data mendarat presisi di Baris 217

Penempatan Presisi (Anti-Top Row)

  • Akar Masalah Sebelumnya: Skrip lama mencari baris kosong dari atas (Row 2), sehingga data surat masuk baru keliru ditulis di baris template atas.
  • Pencocokan Kolom A: Saat menyimpan surat masuk No. Urut 218, skrip mencari baris di Kolom A yang bernilai 218.
  • Mendarat Presisi di Baris 217: Data langsung mengisi Baris 217, tepat di bawah nomor 217 pada Baris 216.
  • Urutan Tampilan Web: Data diurutkan secara ascending (1..217, 218) tanpa melompat ke halaman depan.

Pengarsipan Digital Google Drive

  • Folder Terpusat: Berkas otomatis terorganisir di Arsip Surat SMA YWKA / Surat Masuk 2026.
  • Tautan Publik di Kolom I/J: Guru dan staf dapat mengklik tautan langsung dari Google Sheets untuk membuka berkas asli.
  • Keamanan Hak Akses: Tautan berkas terintegrasi dengan akun Google sekolah.
  • Tampilan Disposisi Langsung: Data surat langsung siap diprint menjadi lembar disposisi resmi.
Integritas & Keamanan Data

Operasi Data Aman: Non-Destructive Update & Safe Delete

Pencegahan rusaknya susunan nomor urut dan baris template saat data diubah atau dihapus

Non-Destructive Update

  • Hanya Mengupdate Konten: Edit surat hanya memperbarui kolom: Perihal, Tanggal, Pengirim, Penerima, dan Keterangan.
  • Kolom No. Urut Terkunci: Kolom A (No. Urut) tidak pernah diubah nilainya.
  • Hasil: Nilai surat di spreadsheet diperbarui tanpa mengubah susunan baris sama sekali.

Safe Clear-Only Delete

  • sheet.deleteRow() Dihindari: Perintah hapus baris fisik dihentikan total karena menyebabkan baris di bawahnya naik dan merusak penomoran.
  • Hanya Kosongkan Sel (Clear-Only): Sistem hanya mengosongkan teks isi kolom B - J/N.
  • Struktur Template Utuh: Nomor Urut tetap ada, slot baris tetap siap dipakai kembali di masa depan.
Ketahanan Jaringan

Mode Offline-First & Mekanisme Auto-Recovery (PWA)

Menjamin staf tata usaha tetap dapat menginput surat saat internet padam tanpa risiko kehilangan data

Penanganan Kondisi Jaringan

  • Deteksi Status Jaringan: Sistem memantau status online/offline browser secara realtime.
  • Antrean Khusus LocalStorage: Saat offline, surat disimpan ke antrean unsynced_surat_keluar atau unsynced_surat_masuk.
  • Penanda Visual 'Draft': Surat yang belum tersinkron diberi lencana status kuning di tabel agar staf mengetahui statusnya.

Sinkronisasi Otomatis (Auto-Sync)

  • Event Listener Reconnect: Begitu internet kembali terhubung, event online langsung memicu fungsi syncAllPendingItems().
  • Pengiriman Latar Belakang: Antrean dikirim satu per satu ke Google Apps Script tanpa perlu staf mengetik ulang data.
  • Verifikasi Sukses: Setelah mendarat di Google Sheets, lencana draft dihapus dan tabel diperbarui otomatis.
Fitur Unggulan

Otomasi Lembar Disposisi & Fitur Ekspor Data

Mendukung percepatan administrasi pimpinan dan pembuatan berkas cadangan offline

Lembar Disposisi Otomatis

  • Popup Otomatis: Sesaat setelah surat disimpan, modal lembar disposisi langsung tampil dengan data terisi lengkap.
  • Kop Resmi SMA YWKA: Memuat identitas sekolah, nomor agenda, tanggal surat, perihal, dan instruksi disposisi.
  • Siap Cetak 1-Klik: Diformat presisi untuk dicetak pada kertas A4 / F4 tanpa margin terpotong.

Salin Cepat & Cadangan CSV

  • Salin Nomor 1-Klik: Nomor agenda lengkap langsung disalin ke clipboard untuk ditempel di Microsoft Word.
  • Ekspor Laporan CSV: Rekapitulasi data surat masuk dan keluar dapat diunduh kapan saja sebagai arsip cadangan.
  • Filter & Pencarian Instan: Pencarian cepat berdasarkan perihal, instansi pengirim, penerima, atau nomor agenda.
